# Application installable en SvelteKit

C'est une application web installable, utilisable hors connexion.

Modèle de départ Bastide (`application-pwa-sveltekit`), écrit par Glowsoft. Il se construit et se déploie sans modification ; la campagne hebdomadaire le construit avec des valeurs d'essai.

## Variables

Aucune variable requise.
